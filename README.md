# Sentiment-topic-dynamic-collaborative-analysis-using-Machine-Learning

## Project Overview
This project focuses on sentiment and topic analysis for public opinion mapping in aviation disaster management.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Pandas
- NumPy
- Scikit-learn

## Dataset
The dataset is used for sentiment and topic analysis.

## Objective
To analyze text data, identify sentiment patterns, and discover important topics using machine learning techniques.
Machine Learning-based sentiment and topic analysis for public opinion mapping in aviation disaster management.
